# 🌸 PinkNotes — Todo List App

PinkNotes is a stylish and functional task management web application built as part of the JavaScript curriculum. It helps users organize their tasks into color-coded projects, set priorities, and keep track of due dates with relative time indicators.

---

## ✨ Features

- **Project Management**: Create, edit, and delete projects with custom color accents.
- **Task Operations**: Add, edit, and remove tasks inside individual projects.
- **Priority Levels**: Assign priority levels (High, Medium, Low) to tasks with visual color indicators.
- **Smart Due Dates**: Date picker validation (prevents past dates up to 2030) and relative date formatting (`Today`, `Tomorrow`, `In X days`, `Overdue`).
- **Data Persistence**: Automatic saving and loading of all projects, tasks, and UI state using `localStorage`.
- **Modular Architecture**: Built using Object-Oriented Programming (OOP) concepts, ES6 Modules, and Webpack.

---

## 🛠️ Tech Stack

- **JavaScript (ES6+)** — Application logic, modules, and OOP structure.
- **Webpack** — Bundler for modular code, CSS processing, and build optimization (development/production split).
- **CSS3 / HTML5** — Custom styling with CSS Variables and responsive modal overlays.
- **localStorage API** — Client-side data persistence.

---

## 🚀 Getting Started

### Prerequisites

- Node.js (v14+ recommended)
- npm

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd todo-list
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run in Development Mode:**
   ```bash
   npm start
   ```

4. **Build for Production:**
   ```bash
   npm run build
   ```

# 🌸 PinkNotes — Приложение Todo List

PinkNotes — это стильное и функциональное веб-приложение для управления задачами, разработанное в рамках курса по JavaScript. Оно помогает организовывать задачи по проектам с цветовым кодированием, устанавливать приоритеты и отслеживать сроки выполнения с помощью понятных индикаторов времени.

## ✨ Возможности

- **Управление проектами**: Создание, редактирование и удаление проектов с персональным цветовым оформлением.
- **Работа со задачами**: Добавление, редактирование и удаление задач внутри каждого проекта.
- **Уровень приоритета**: Присвоение приоритетов (Высокий, Средний, Низкий) с визуальными цветовыми метками.
- **Умные даты (Due Dates)**: Валидация выбора даты (ограничение от сегодняшнего дня до 2030 года) и форматирование относительных дат (`Today`, `Tomorrow`, `In X days`, `Overdue`).
- **Сохранение данных**: Автоматическое сохранение и загрузка проектов, задач и состояния интерфейса с помощью `localStorage`.
- **Модульная архитектура**: Приложение построено с использованием Объектно-Ориентированного Программирования (ООП), ES6-модулей и Webpack.
